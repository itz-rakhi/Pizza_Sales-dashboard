# Pizza_Sales-dashboard
🍕Pizza Sales Insights Dashboard
📌 Short Description
A dynamic, interactive Power BI dashboard designed to analyze pizza sales data from 2015. The dashboard uncovers customer preferences, sales trends, and product performance to support data-driven decision-making in the food retail industry.

🛠 Tech Stack
Power BI Desktop – Main data visualization platform used for report creation
Power Query – Data transformation and cleaning layer for reshaping and preparing the data
SQL – Querying and preparing datasets for analysis
Excel – Preprocessing and cleaning raw data
File Format: .pbix for development and .png for dashboard previews

📂 Data Source
Source: Pizza Sales Dataset on Kaggle
Content: Transactional data covering pizza orders throughout 2015, including order dates, pizza categories, sizes, quantities, and prices.

✨ Features / Highlights
Business Problem
Pizza chains generate significant revenue, but managers often lack an intuitive way to track KPIs, identify peak demand periods, and evaluate product performance.

Goal of the Dashboard
To deliver an interactive visual tool that:
Tracks key KPIs like revenue, order value, and pizzas sold.
Identifies daily and monthly sales trends.
Highlights best and worst sellers for product strategy.
Provides insights into category and size preferences.

Walkthrough of Key Visuals
Key KPIs (Top Panel):
Total Revenue: $817.86K
Avg Order Value: $38.31
Total Pizzas Sold: 49,574
Total Orders: 21,350
Avg Pizzas per Order: 2.32

Daily Trend (Bar Chart): Shows busiest days, with peak orders on Thursday–Saturday evenings.
Monthly Trend (Line Chart): Reveals seasonality, with July and January as peak months.
Sales by Category (Pie Chart): Classic pizzas lead with 26.91% of sales.
Sales by Size (Pie Chart): Large pizzas dominate with 45.89% of sales.
Best Sellers (Bar Charts): Thai Chicken Pizza tops revenue (~43K).
Worst Sellers (Bar Charts): Brie Carre Pizza underperforms across all metrics.

Business Impact & Insights
Marketing Optimization: Promote large-sized pizzas and classic category offerings.
Menu Strategy: Reassess underperforming pizzas like Brie Carre.
Operational Planning: Staff more during peak evenings and months.
Customer Behavior: Average of 2.32 pizzas per order shows strong upselling potential.
